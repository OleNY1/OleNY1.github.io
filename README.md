# Oleh Goumain — Portfolio

Personal portfolio site showcasing projects, skills, and contact information. Built with HTML, CSS, and vanilla JavaScript.

**Live site:** [oleny1.github.io](https://oleny1.github.io/)

## Features

- Responsive layout with bento-style sections
- Featured projects with screenshots and links to GitHub repos
- About section aligned with education and skills
- Contact section (email, location, LinkedIn)
- Smooth scrolling, scroll animations, and mobile navigation

## Run locally

No build step required. From this folder:

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser.

## Deploy

This site is published via [GitHub Pages](https://pages.github.com/) from the [OleNY1/OleNY1.github.io](https://github.com/OleNY1/OleNY1.github.io) repository. Push changes to `main` on that repo to update the live site.
