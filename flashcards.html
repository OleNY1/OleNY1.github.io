📚 HTML Elements Flashcards

🏗️ Section Tag

Click to learn about the <section> element

Section Tag

Purpose: Groups related content into distinct parts of a document.

Semantic: Helps screen readers and search engines understand page structure.

<section id="about">
  <h2>About Me</h2>
  <p>My story...</p>
</section>

Benefits: Accessibility, SEO, navigation, code organization

📝 Span Tag

Click to learn about the <span> element

Span Tag

Purpose: Inline container for styling or targeting specific text.

Inline Element: Doesn't create line breaks, flows with text.

<p>Hello <span class="highlight">world</span>!</p>

Common Uses: Highlighting text, applying styles, JavaScript targeting

vs Div: Span is inline, div is block-level

📦 Div Tag

Click to learn about the <div> element

Div Tag

Purpose: Generic block-level container for grouping elements.

Block Element: Creates line breaks, takes full width.

<div class="hamburger">
  <span class="bar"></span>
  <span class="bar"></span>
  <span class="bar"></span>
</div>

Why under hamburger: Groups the three lines together for styling and JavaScript targeting

🔍 Meta Tag

Click to learn about <meta> tags

Meta Tag

Purpose: Provides metadata about the HTML document.

Placement: Always in the <head> section.

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="My portfolio">

Common Uses: Character encoding, viewport settings, SEO descriptions, social media cards

🎨 I Tag

Click to learn about the <i> element

I Tag

Purpose: Represents text in an alternate voice or mood (italic).

Semantic: Indicates emphasis, foreign words, technical terms, thoughts.

<p>The word <i>bonjour</i> means hello in French.</p>
<i class="fas fa-code"></i> <!-- Font Awesome icon -->

Common Uses: Foreign words, technical terms, icons (with Font Awesome)

Note: Often used for icons in modern web development

📝 Input Tag

Click to learn about the <input> element

Input Tag

Purpose: Creates interactive form controls for user input.

Self-closing: No closing tag needed.

<input type="text" placeholder="Your name" required>
<input type="email" placeholder="Your email">
<input type="password">

Common Types: text, email, password, number, date, file, submit

Attributes: type, name, placeholder, required, value

📄 Textarea Tag

Click to learn about the <textarea> element

Textarea Tag

Purpose: Multi-line text input field for longer content.

Resizable: Users can resize the text area.

<textarea placeholder="Your message" rows="5" cols="50"></textarea>

Common Uses: Comments, messages, descriptions, long-form content

Attributes: rows, cols, placeholder, required, maxlength

📋 Form Tag

Click to learn about the <form> element

Form Tag

Purpose: Container for form elements that collect user data.

Submission: Handles form submission and data processing.

<form action="/submit" method="POST">
  <input type="text" name="name">
  <textarea name="message"></textarea>
  <button type="submit">Send</button>
</form>

Attributes: action (where to send), method (GET/POST)

⚙️ Type & Required

Click to learn about these attributes

Type & Required Attributes

Type Attribute: Specifies the input type and behavior.

<input type="text"> <!-- Text input -->
<input type="email"> <!-- Email with validation -->
<input type="password"> <!-- Hidden text -->
<input type="submit"> <!-- Submit button -->

Required Attribute: Makes the field mandatory for form submission.

<input type="email" required> <!-- Must be filled -->
🔧 Script Tag

Click to learn about <script src="Index.js"></script>

Script Tag

Purpose: Links external JavaScript file to the HTML document.

Function: Loads and executes JavaScript code from Index.js file.

<script src="Index.js"></script>

What it does:

  • Loads mobile navigation functionality
  • Enables smooth scrolling
  • Handles form submission
  • Adds animations and interactions
  • Manages theme toggle

Placement: Usually at the end of <body> for better performance
